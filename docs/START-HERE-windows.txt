在场 · StillHere — Windows 快速开始（0.2.0 Beta）

1. 先将压缩包完整解压到一个保留的位置（例如文档中的 StillHere 文件夹）。
2. 双击 StillHere.exe。应用会出现在系统托盘，首次打开会显示设置窗口。
3. 点击「选择壁纸」，进入本文件夹的 Wallpapers，可选择随包附带的 8 张原创壁纸，也可以选择自己的图片。
4. 按 Ctrl + Alt + Shift + P 开启防窥，再按一次直接退出；也可以通过托盘菜单操作。

首次开启会进行采集兼容性检查。检查不通过时不会开启防窥。Windows 10 2004（19041）或更新版本，需 .NET Framework 4.8。

本版本尚未进行 Windows 代码签名，系统或浏览器可能显示未知发布者提示。请确认下载来源和校验值，谨慎决定是否运行。

防窥时电脑仍可操作，知道快捷键的人可直接退出；它不等同于系统锁屏。远程与自动化软件使用的采集方式各不相同，请先用自己的工具测试画面和操作。本版本未完成独立 UU 实时远控验收。
