# 在场 · StillHere 0.1.0

首个可用预览版：离席时在物理显示器上显示自选壁纸，保持桌面会话及自动化操作继续运行，无需维持远程连接。

- 原生菜单栏应用，Control + Option + Command + P 显式开启或请求退出。
- 保护所有已连接显示器，壁纸层不取得键盘焦点、不接收普通鼠标事件。
- 退出防窥和受保护状态下退出应用均要求应用密码。
- 首次开启及系统 build 变化后进行采集兼容性检查；检查失败时不铺满屏幕。
- 可以使用已有录屏权限的终端执行 `StillHere --diagnose`，无需给 GUI 新增录屏授权。
- 默认内置“我司雇我在”水豚哲学梗图，支持替换本地图片。

已在 macOS 15.5 / 24F74、两块连接的显示器上检查采集排除，并通过真实原生自动化的截图、点击、输入、再次截图和密码流程。7 项核心检查通过。Apple Silicon 与 Intel 通用包已构建，Intel 实机运行尚未验收。

物理屏幕的肉眼确认、独立 UU 实时远控会话以及其他 macOS 版本尚未完成验收。采集排除依赖系统与工具实际行为，不保证适用于所有版本和采集路径。该版本使用本地 ad-hoc 签名，尚未经过 Apple 公证。

下载 DMG 后将 StillHere.app 拖入 Applications，首次运行设置自己的退出密码。发布包没有共享默认密码；密码、个人图片和本机运行状态不包含在仓库中。
