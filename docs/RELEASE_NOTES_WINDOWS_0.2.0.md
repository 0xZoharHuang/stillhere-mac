# 在场 · StillHere 0.2.0 for Windows — Beta

按 **Ctrl + Alt + Shift + P** 开启隐私壁纸，再按一次直接返回桌面；不再需要密码。壁纸画面上不显示快捷键提示。托盘也可以开启或解除防窥，退出应用会移除壁纸。

自选壁纸与唤醒设置继续可用。旧版密码校验文件仍保留在本机，此版本不会读取或使用它。知道快捷键的人也可以直接退出，防窥提供离席时的画面遮挡，不替代系统锁屏。

Windows 10 build 19041 或更新版本及 .NET Framework 4.8。首次开启先进行采集检查；若快捷键无法注册或检查不通过，应用不会开启保护。本版本未进行 Windows 代码签名。实际运行环境与远控兼容性以验收记录为准。
