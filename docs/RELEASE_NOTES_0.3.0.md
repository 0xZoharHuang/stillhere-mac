# 在场 · StillHere 0.3.0 for macOS — Beta

按 **Control + Option + Command + P** 开启隐私壁纸，再按一次直接返回桌面；不再需要密码。壁纸画面上不显示快捷键提示。菜单栏也可以开启或解除防窥，退出应用会移除壁纸。

图库、自选壁纸和唤醒设置继续可用。已保存的旧版密码校验文件不会被删除，但此版本不会读取或使用它。知道快捷键的人也可以直接退出，防窥提供离席时的画面遮挡，不替代系统锁屏。

系统更新后会重新检查采集兼容性；若快捷键注册失败或采集检查不通过，应用不会开启保护。Apple Silicon 和 Intel 通用构建；实际运行环境、读屏方式及独立远控兼容性请以验收记录为准。此版本使用 ad-hoc 签名，尚未经过 Apple 公证。
