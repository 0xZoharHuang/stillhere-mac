# 在场 · StillHere 开箱包 — Beta

下载适合自己系统的文件：

- **Mac：`StillHere-0.3.0-mac-ready.dmg`**。打开后把应用拖进 Applications，使用镜像内的中文快速开始说明。应用内置 8 张原创壁纸。
- **Windows：`StillHere-0.2.0-windows-ready.zip`**。完整解压后双击 `StillHere.exe`，中文快速开始说明与 8 张壁纸位于同一文件夹；在应用中点击「选择壁纸」，进入 `Wallpapers` 文件夹选择。
- **`SHA256SUMS-ready.txt`** 可用于校验两个下载文件。

本次只增加使用说明和完整壁纸资产，Mac 0.3.0 与 Windows 0.2.0 程序本体分别与之前验证过的版本完全一致。Mac 为通用构建，Windows 需要 Windows 10 2004 或更新版本及 .NET Framework 4.8。

这是 Beta：Mac 应用采用 ad-hoc 签名，尚未通过 Apple 公证；Windows 可执行文件未签名，首次打开时可能出现系统提示。下载前请核对来源和校验值。各机器的实际采集与输入路径可能不同；此次版本尚未独立完成 UU 实时远控验收。防窥画面可用快捷键直接退出，不替代系统锁屏。

详细验证：[Mac 记录](https://github.com/0xZoharHuang/stillhere-mac/blob/main/verification/application-macos15.5-v0.3.0.json) / [Windows 记录](https://github.com/0xZoharHuang/stillhere-mac/blob/main/verification/application-windows10-v0.2.0.json)。
