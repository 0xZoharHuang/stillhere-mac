在场 · StillHere — Mac 快速开始（0.4.0 Beta）

1. 将「在场 · StillHere」应用拖到 Applications（应用程序）文件夹，双击打开。
2. 在菜单栏点击「在场」，选择「壁纸与设置」，在壁纸库中选择图片。
3. 按 Control + Option + Command + P 开启防窥，再按一次退出。

首次开启会进行屏幕采集兼容性检查；如系统请求屏幕录制权限，请按照系统提示操作。检查不通过时不会开启防窥。可在偏好设置中选择防窥时是否保持电脑和显示器唤醒；系统锁屏、合盖和关机仍由系统控制。

本版本尚未使用 Developer ID 签名及 Apple 公证，macOS 可能阻止首次打开。请先确认下载来源和校验值，再参考 Apple 官方说明：https://support.apple.com/zh-cn/102445

防窥时电脑仍可操作，知道快捷键的人可直接退出；它不等同于系统锁屏。远程与自动化软件使用的采集方式各不相同，请先用自己的工具测试画面和操作。本版本未完成独立 UU 实时远控验收。

项目和更新：https://github.com/0xZoharHuang/stillhere-mac

ENGLISH — QUICK START
1. Drag StillHere.app to Applications and open it.
2. Open the menu-bar app, choose 壁纸与设置 (Wallpaper & Settings), then 壁纸库 (Wallpaper Library).
3. Press Control + Option + Command + P to show the privacy wallpaper; press it again to return to your desktop.

The interface is currently in Chinese. First use runs a capture compatibility check and may request Screen Recording permission. If the check fails, privacy will not turn on. macOS locking, sleep and closing the lid are controlled by macOS.

This Beta is ad-hoc signed and not notarized; macOS may prevent it from opening. Check the download and checksum, and see Apple's guidance: https://support.apple.com/en-us/102445

Anyone who knows the shortcut can exit privacy, and the desktop remains operable. This is not a replacement for the system lock screen. Test your own remote-control and automation tools before relying on it; live UU Remote compatibility has not been independently verified for this build.
