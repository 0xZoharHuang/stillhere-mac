# StillHere · 在场 — Bilingual Wallpaper Collection / 双语壁纸版

**Step away. Your work stays. 人可以离席，工作继续在场。**

This Beta introduces **24 original Chinese–English wallpapers**, with office humor and AI-agent jokes. The collection includes “Either the code runs, or I do,” “I asked a question. It started refactoring,” and the original capybara. Existing Mac wallpaper choices remain compatible.

- **macOS 0.4.0:** download `StillHere-0.4.0-mac-ready.dmg`, open it, and drag the app to Applications. The 24 images are built into the wallpaper library.
- **Windows 0.2.0 + new collection:** download `StillHere-0.2.0-windows-ready.zip`, extract the entire archive and open `StillHere.exe`. Choose from the 24 images in the `Wallpapers` folder. The Windows executable is unchanged from the previously tested 0.2.0 build.
- Both packages include Chinese and English quick-start instructions. The application interface itself is currently Chinese.

**24 张原创中英双语壁纸**，包括「我和代码，总有一个能跑」「我就问了个问题，它开始重构了」，以及保留的「我司雇我在」。Mac 内置图库；Windows 开箱包的 `Wallpapers` 文件夹包含同一组图片。

Toggle with **Control + Option + Command + P** on Mac or **Ctrl + Alt + Shift + P** on Windows. No password is required, and the wallpaper does not reveal the shortcut. This is a visual cover, not a system lock screen: anyone who knows the shortcut can exit, and the underlying desktop stays interactive.

This release remains a Beta. The Mac app is ad-hoc signed and not notarized; the Windows executable is unsigned. Activation is gated by a capture compatibility check, but capture behavior differs between OS versions and applications. Test your own automation and remote tools. The current release has not independently completed a live UU Remote video-and-input acceptance.
