# 在场 · StillHere 0.2.0 for macOS — Beta

「在场」重新设计为三个页面：概览、壁纸库与偏好设置。概览展示当前壁纸与桌面状态，并提供直接开启防窥的主操作；壁纸库内有四张原创壁纸，也可以选择自己的图片。密码修改和唤醒选项收纳在偏好设置，退出密码对话框同步更新。

原有的「我司雇我在」之外，新增「本来可以是封邮件」「人在休息，活在运行」「正在装作不在工位」。壁纸选择会保存在本机。旧版的自选壁纸、唤醒偏好与退出密码继续使用。

已验证：macOS 15.5 / Apple Silicon，两块显示器；独立配置下验证新主按钮开启、快捷键打开密码框、错误密码、取消、正确密码退出与资源释放。壁纸选择在重启后保留；旧版自选壁纸偏好迁移测试通过。8 项 Swift 测试通过，Apple Silicon 和 Intel 架构均成功构建；Intel 硬件尚未实机测试。安装包使用 ad-hoc 签名，尚未通过 Apple 公证。

防窥继续依赖当前系统和具体采集方式，请在你的实际远控和自动化程序中验证。保持桌面可操作意味着它不能替代系统锁屏。应用异常退出后遮挡也会消失；本版本没有自动离席或自动恢复防窥的保证。

Windows 保持独立的 [0.1.0 Beta](https://github.com/0xZoharHuang/stillhere-mac/releases/tag/windows-v0.1.0)，本次界面与壁纸库重构仅针对 macOS。
